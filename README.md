## Overview

ResumeNexa is a full-stack career platform that combines resume creation, AI-assisted resume analysis, and job discovery into a single application.

The platform enables users to create professional resumes using customizable templates, evaluate resumes with Generative AI, and search job openings from multiple companies without switching between different portals.

Designed with scalability and modern web technologies, ResumeNexa provides a seamless experience for students, fresh graduates, and professionals looking to improve their job application workflow.
